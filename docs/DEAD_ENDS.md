# DEAD_ENDS.md — 已否定的路线

每条记录：路线、否定日期、否定证据。**重新尝试前先读完否定理由，确认边界条件真的变了。**

## 过滤与下载

### X1. 用关键词过滤拦截非图像对象（PR/KO/SR 等）
- 否定：2026-08-31。KEY_IMAGES PR 靠 'KEY' 关键词拦截，但关键词列表可被任务级参数替换/绕开（nonce 事件）。
- 正解：按模态本质过滤（`NON_IMAGE_MODALITIES` + 接收端 PixelData 缺失检查），无条件、不可被 options 关闭（D3）。

### X2. 用 nonce 关键词（如 `XRAY_GAPFILL_NONCE_*`）变相关闭衍生过滤
- 否定：2026-08-31，192.0.0.211 生产事故。`derived_keywords` 是替换语义，传 1 个词 = 拆掉全部 48 个默认关键词。
- 正解：关闭过滤用 `exclude_derived: False`；追加关键词用 `extra_derived_keywords`（D7）。

### X3. 接收端对拒收序列返回 C-STORE 失败码
- 否定：2026-05。部分 PACS 会因此中止整个 C-MOVE，一个坏序列毁掉整个检查。
- 正解：返回 0x0000 但不落盘（D2）。

### X4. 短子串关键词裸匹配（'3D'、小写 'nodule' 等）
- 否定：2026-05-14（'3D' 误杀原始 MR 序列，17ee220）；2026-08（'nodule' 小写死代码 + 会误伤 "Lung Nodule FU" 随访协议）。
- 正解：关键词两侧 upper 归一化 + 例外表；新增关键词先排查厂商诊断序列命名碰撞（D5）。

### X5. 按 atime 做磁盘清理排序
- 否定：2026-08。relatime 下清理自身的目录遍历会刷新 atime；Windows NTFS 常不更新 atime。
- 正解：max(mtime, ctime) + min-age 保护（D10）。

### X6. 让磁盘清理守护进程管 `results/cache/`
- 否定：2026-08。曾一次删掉 38GB 缓存并与 LRU 淘汰竞争 → WinError 3/5。
- 正解：cache 目录由 `cache.py` 的 LRU 自管理，清理跳过（D10）。

### X7. 全局 setter 修改过滤关键词
- 否定：2026-08。多任务并发时全局状态互相污染。
- 正解：任务级 `options.derived_keywords` / `extra_derived_keywords`（D7）。

## 图像处理

### X8. QC 阶段盲翻转修正方位（`detect_nifti_orientation_error`）
- 否定：2026-08-27。对已归一化的数组会二次翻转；无法区分 dcm2niix 的输出布局族。
- 正解：转换时探针验证（D11），QC 版退役为恒 False。

### X9. QC 边框-vs-中心灰度反转启发式（`GRAYSCALE_INVERTED`）
- 否定：2026-08-31。胸部 CT 解剖学上恒成立（边框=胸壁 > 中心=肺空气），会把健康体数据静默反转并摘除低质量标记；背景排除规则（flat > max×0.001）又把 62% 体素排除导致动态范围失真、阈值失效。
- 正解：转换时探针按 |corr| 选择，强负相关才反转（D11/D12）。

### X10. 预览图缩放+居中放置到正方形画布（`normalize_2d_preview`）
- 否定：2026-08-19（14c1146）。破坏原始长宽比信息。
- 正解：保持长宽比，target_size 只限最大边（D13）。

### X11. 预览层对 2D 图像加 canonical/翻转逻辑
- 否定：2026-08-27。与转换时归一化双重作用。
- 正解：`_load_image_2d` 对 2D 直接用原始数组（D13）。

### X12. 预览回退时用边角/解剖启发式判断 MONOCHROME1 极性
- 否定：2026-08-31。紧密 FOV 图像边角含骨盆等亮组织会误判反转。
- 正解：窗口不可信时一律按 MONO2 诊断极性渲染（已观测的窗口损坏设备全部为 MONO2 极性存储）（D14）。

### X13. 无条件信任 DICOM 窗宽窗位 / PhotometricInterpretation 标签
- 否定：2026-08-31。Mindray DX 两层说谎（窗口与像素完全不匹配 + PI 假）；LandWind 16bit 数据窗口开在 ~10000 而数据在 ~50000-63000。
- 正解：覆盖率 + 中位数出窗双重校验，不可信则 p1–p99.5 自适应（D14）。

### X14. 单纯禁止 3D 图像的 QC 反转修正
- 否定：2026-08-31。胸部 CT 误杀概率高，但 MR 确实存在偶发真实反转，不能因噎废食。
- 正解：反转修正统一收敛到转换时探针验证路径，对错有像素级证据（D12）。

## 部署与并发

### X15. 多实例/多进程部署分摊负载
- 否定：2026-08-27。C-STORE SCP 绑定固定端口，eventlet 下 SO_REUSEPORT 让两进程同时 LISTEN，任务状态被撕裂。
- 正解：单实例锁 + 任务队列（D20）。

### X16. 提高 ThreadPoolExecutor  workers 数来"补偿"卡死线程
- 否定（作为单独手段）：2026-09-05。只加线程不修闸门计数，`_running_task_count` 仍会泄漏；只修计数不加冗余线程，新任务会在 executor 内部队列饿死。两者必须同时做。
- 正解：闸门释放 + 冗余线程 + 超时看门狗三件套（D17）。

### X17. 依赖 DEBUG 级日志做事后溯源
- 否定：2026-08-31。生产日志是 INFO 级，提交来源 IP 记在 DEBUG → nonce 事故无法定位元凶。
- 正解：关键审计信息（提交 IP + options）必须 INFO 级（D21）。

### X18. `pkill -f` 远程重启服务
- 否定：2026-08。模式会匹配到 ssh 远程 shell 自己的命令行，会话自杀。
- 正解：精确 `kill <pid>`，且先确认旧进程死亡再启动（单实例锁会拒绝第二实例）（D20）。
